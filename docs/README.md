## 🔧 Prerequisites

Before using these guides, ensure you have:

- **Python 3.11+** installed
- **uv** package manager
- **LangSmith account** (free at [smith.langchain.com](https://smith.langchain.com))
- **API keys** for your chosen LLM provider (Google Gemini, OpenAI, etc.)
